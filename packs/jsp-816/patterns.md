# Patterns — jsp-816

## Stand up organisational EMS from Framework
**When:** a Defence organisation needs an EMS mapped to JSP 816.
**How:** adopt PDCA; map activities to 12 Elements; write Expectations into roles and procedures; set MI and assurance cadence; run Annex A self-assessment annually.
**Trade-offs:** full Element coverage is heavy for small units — proportionate depth still must hit compulsory musts.

## Aspect-led risk control
**When:** choosing where to put environmental controls.
**How:** build aspect register (E4.1); score significance; apply controls; set escalation (E4.3); re-open on change (E4.6).
**Trade-offs:** exhaustive registers stall teams; focus on significant aspects without dropping legal obligations (E3).

## Delegation with competence evidence
**When:** appointing people to control environmentally significant work.
**How:** define authority (E5.1); verify competence (E5.2/E6.5); record delegation (E5.4); include stop-work (E5.6).
**Trade-offs:** wide delegation speeds delivery but raises assurance burden on competence records.

## Three-lines assurance rhythm
**When:** planning EMS assurance.
**How:** 1LOD continuous risk-based checks; enable 2LOD/3LOD; annual toolkit self-assessment; leadership review; corrective action tracker.
**Trade-offs:** heavy 3LOD without 1LOD evidence wastes audit effort.
