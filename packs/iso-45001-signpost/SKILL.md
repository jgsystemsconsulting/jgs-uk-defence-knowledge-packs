# ISO 45001: Signpost (pointers only)

**This is a signpost, not a knowledge pack.** It carries **no source content**:
no reproduced clauses, no synthesised summaries of normative text. ISO 45001
is Excluded under this repo's `docs/SOURCE-VETTING.md` (third-party ISO material
outside Open Government Licence; paywalled, no redistribution grant), so it is
not reconstituted into a pack. What this skill does: tell you what ISO 45001
is by designation and title, who owns it, that it is not redistributable here,
and where to get an authentic copy.

## When to use

You need to **identify** ISO 45001 or **locate** where the authentic text lives
(for example "what is ISO 45001?" or "where do I get ISO 45001?"). It routes you
to the authoritative catalogue. It does **not** answer clause, requirement, or
guidance questions from the standard.

**Prerequisites:** none. Plain Markdown.

## How to use

Read the row below. **Status** tells you redistributability:

- Excluded: paywalled or no redistribution grant; buy or download from the owner. Cannot be packaged here.

Where licence permits citation of the catalogue location, the owner's official
catalogue page is given in the Status cell. **Never quote standard text** in
any answer that uses this signpost.
